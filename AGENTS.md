# AGENTS.md

Tauri 2 desktop app: Vue 3 + TypeScript frontend in `src/`, Rust backend (SQLite/Diesel) in `src-tauri/`. pnpm for JS, Cargo for Rust.

## Commands

- Dev: `pnpm tauri:dev` (starts Vite on port 1420 — port is pinned in `src-tauri/tauri.conf.json`)
- Frontend typecheck: `pnpm type-check` (`vue-tsc --build`)
- Lint: `pnpm lint` (auto-fixes), format check: `pnpm format:check`
- Rust checks run from `src-tauri/`:
  - `cargo fmt --check`
  - `cargo clippy --all-targets --all-features -- -D warnings`
  - `cargo test --workspace --all-targets`
- CI order (PRs to `dev`): `format:check` → `lint` → cargo fmt → clippy → cargo test. No JS test suite exists; verification = vue-tsc + Rust tests.

## Diesel / migrations

- `src-tauri/src/db/sqlite/schema.rs` is **generated by Diesel CLI** — never edit by hand.
- Migrations live in `src-tauri/migrations/` and are embedded at compile time (`embed_migrations!()` in `src-tauri/src/db/sqlite.rs`). After adding a migration, regenerate schema via diesel CLI (`diesel migration run`, uses `.env`'s `DATABASE_URL=movies.db`).

## Conventions

- Versions must match exactly in three files: `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`. The release workflow hard-fails on mismatch.
- Branching: PRs target `dev`; merges into `main` trigger multi-platform build, GitHub Release, and auto-update manifest generation.
- Prettier: no semicolons, single quotes, 120 col width, tailwind class sorting enabled.
- Linux builds need system deps: `libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev patchelf`.
